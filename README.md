# Ayah Tab

Chrome extension that shows a new Quran ayah (with translation, tafsir and audio) on every new tab.
Data from the [AlQuran Cloud API](https://alquran.cloud/api).

## Install
1. Download/clone this repo
2. Open `chrome://extensions`, enable Developer mode
3. Click "Load unpacked" and select the repo folder

The same page is also viewable on GitHub Pages.
